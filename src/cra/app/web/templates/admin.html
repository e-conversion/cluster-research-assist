How to create a library
  1. Collect the files in one directory on your own machine, never in a repository. papers.csv is required; each of abstracts.json, fulltexts.json, pis.json, embeddings.npz, graph.json and proposal.md switches on the tools that need it.
  2. Run pip install "cluster-research-assist[build] @ git+https://github.com/e-conversion/cluster-research-assist", then cra library manifest <directory> and cra library migrate <directory> <bundle>. It merges the files into clean records and checks that nothing was lost.
  3. With embeddings, run cra library build <bundle>. It computes the publication map and rewrites manifest.json.
  4. Run cra library check <bundle>. It applies the checks an upload has to pass and prints what the library holds.
  5. Pack it with tar -czf library.tar.gz -C <bundle> . and upload the archive here.
